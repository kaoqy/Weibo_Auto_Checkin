# v1.3.0 架构与数据流

```text
浏览器工作台
  ├─ 账号勾选 / 一键签到 ────────┐
  └─ 超话浏览 / 筛选 / AI 总结 ──┤
                                 ▼
FastAPI（认证、参数校验、统一错误）
  ├─ /api/checkin ───────────────┤
  └─ /api/topics ────────────────┤
                                 ▼
调度与业务服务
  ├─ Scheduler：任务锁、代理分组、执行进度
  ├─ CookieSession：账号锁、保活、退避、条件持久化
  ├─ TopicService：多页抓取、游标保护、缓存、样本筛选
  └─ AIService：非流式 / SSE / JSON 降级、统一事件输出
                                 ▼
外部与持久化
  ├─ 微博：登录态、关注列表、签到、帖子
  ├─ OpenAI 兼容接口：chat/completions
  └─ SQLite：账号、勾选、任务、日志、超话与帖子缓存
```

## 关键约束

- `run_account_checkin` 的 `account_id` 是公开调用契约；调度器传入后，客户端必须应用账号的超话勾选范围。
- 同一账号的签到与 Cookie 保活串行执行；数据库条件写入防止旧请求覆盖新凭证。
- 超话摘要使用同一次抓取、同一筛选样本生成，统计与 AI 上下文保持一致。
- AI 输出统一为 `meta`、`text`、`finish`、`error` 事件。普通 JSON、SSE 分片、CRLF 和末尾未换行都必须得到可见结果或错误。
- 页面请求具备取消与过期响应保护，旧超话/旧筛选的响应不能覆盖当前面板。
